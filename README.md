# machi.

**データと部品から、地図アプリをつくる。**

Excel・CSV・TSV・公開Googleスプレッドシートを取り込み、地図・検索・カテゴリ・一覧・詳細などの部品を配置するブラウザーエディターです。PCとスマホの画面を編集し、その場で操作を試せます。

**[machi.を開く](https://yuqio-dev.github.io/machi./)**

## 使い方

1. 地点データ0件のテンプレートから始めます。「データ」で地点名・緯度・経度などの列を対応付け、掲載する項目を選んで取り込みます。
2. 「部品」で地図・検索・一覧・入力・ボタンなど25種類を配置します。右側で位置、外観、使用するデータ列、トリガーを設定します。
3. 「試す」で検索・絞り込み・地点詳細・画面遷移を確認します。PCとスマホはそれぞれ配置を持ちます。
4. 「地図をダウンロード」で閲覧用HTMLを取得します。「プロンプト」では外部AI向けの実装指示を生成できます。

「プロジェクト」から新しい地図、架空データの地図サンプル、汎用画面サンプルを開けます。サンプルの施設名・地点情報は架空です。[入力例](examples/import/README.md)と[レイアウト例](examples/templates/README.md)も同梱しています。

## 保存とデータ

設計と取り込みデータは、利用中のブラウザーのIndexedDBへ保存します。共同編集、サーバー保存、端末間の自動同期はありません。バックアップや端末間の移動には「設計JSONを書き出す／JSONを読み戻す」を使ってください。

公開Googleスプレッドシートは読み取り専用です。非公開シートへのログイン、自動同期、元シートへの書き込みは行いません。掲載対象から外した列と接続URLは、閲覧用HTMLやAI向け実装指示に含めません。JSONのバックアップには設計全体と取り込みデータが含まれます。

## 開発

Node.js 24以降を使用します。

```sh
npm ci
npm run dev
npm run build
npm test
npm run preview
```

開発時はViteが表示するURL、本番ビルドの確認は http://127.0.0.1:5173/ を開きます。プレビューポートは環境変数 MACHI_PORT で指定できます。確認データの再生成は npm run build:examples です。

## リポジトリ構成

- src/editor/: エディター、共通部品、実行プレビュー、設計形式と検証。
- src/data/: 表の読み込み・列対応・検証・公開シートの取得。
- src/vendor/: SheetJSとそのライセンス。
- examples/: 架空データの入力例と地図テンプレート。
- scripts/: ビルド・プレビュー・サンプル生成。
- tests/: 設計検証、データ取り込み、編集、保存、閲覧用HTMLの回帰テスト。
- dist/: ビルド出力。Gitには含めず、GitHub Actionsで生成してPagesへ公開。

mainの更新時に .github/workflows/pages.yml がビルドとテストを行い、成功した場合に公開します。以前のエディターURL /builder/sketch/ と /builder/ はトップへ転送します。

## 制限とライセンス

表は1,000行・50列・8MBまでです。背景地図はOpenStreetMapを使用し、出典を表示します。背景地図、外部画像、Google Fontsには通信が必要です。外部AIが生成したアプリと設計の完全な一致は別途検証が必要です。

第三者ライブラリ・フォントの表示は src/editor/public/ と src/vendor/ にあります。
