# machi. スケッチエディター

地図アプリの画面と操作を設計するブラウザーアプリです。既存の `/builder/` は変更せず、`/builder/sketch/` に静的ファイルを出力します。利用者側のインストールは不要です。実装状況と不足は `design/machi-implementation-targets.md` に記録します。

## 起動とビルド

```powershell
npm run build:sketch
npm run dev
```

`http://127.0.0.1:5173/builder/sketch/` を開きます。5173が使用中なら、`$env:USHIKU_MAP_PORT='5181'` を設定して `npm run dev` を実行します。

ビルド前に `scripts/prepare-sketch.mjs` が、同じ作業場所に `../design/machi-contracts/` があればSchema・部品定義・牛久サンプルを `contracts/` へコピーします。単独のGitクローンでは、リポジトリに同梱した契約スナップショットを使います。契約を変更する場合は元の資料を更新し、スナップショットを同期してからビルドしてください。Viteの出力削除対象は `dist/builder/sketch/` のみです。

## 現在の実装

- 地図、ヘッダー、検索、カテゴリ、件数、一覧、詳細、ボタン、テキストを追加・選択できます。
- 位置・大きさ・重なり順、端末別の表示、簡単な外観、データ項目、イベントと操作先を設定できます。
- 「試す」では検索・カテゴリ、地点一覧・地図ピン・詳細が共通の実行状態を使います。条件外になった選択地点は解除されます。
- 画面を追加して、画面移動・戻るの操作先にできます。
- IndexedDBへ設計と地点データを保存します。パネル幅など作業環境はlocalStorageに分けます。
- 設計JSONの書き出し・読み戻し、Schemaと参照・公開列・親循環・値の型の検査、属性別の差分、取り込み後Undoに対応します。
- 外部AI向けMarkdownには設計JSONと掲載列だけを含め、コピーまたは保存できます。
- 左右パネル幅、キャンバス縮尺、配置操作は前段の試作で操作確認済みです。確認条件は `../../../design/machi-preflight-review.md` に記録しています。

## データ取り込みと残る制限

- Excel・CSV・TSV、表の貼り付け、公開Googleスプレッドシートの取り込みを実装しています。シート・見出し行・列対応・掲載項目を選び、不正行の除外を確認して反映します。取り込みは最初のデータセットの置き換えです。Googleの実URLからの取得は今回のブラウザー試験では未確認です。
- 39部品のうち、最初のフロー向け9部品を追加・設定・描画します。他の部品は未対応表示です。
- 複数選択後の一括移動・サイズ変更、親子部品の相対座標、旧形式JSONの移行、完全な書き出し一式、生成アプリとの実行照合は未実装です。
- 2026-10-23にビルド・TypeScript型検査・34件のテストが成功しました。ブラウザーでExcelの2シート、貼り付け、不正行確認、検索・絞り込み・詳細、保存復元、Undo/Redo、内部列を除いたAI出力を確認しました。記録は `../../../design/verification/sketch-flow/report.md` にあります。
- Viteのチャンクサイズ警告は残っています。表取り込み画面とSheetJSは使用時に読み込みますが、エディター本体は約976KBです。
- shadcn/ui・Tailwind CSSはまだ導入せず、既存スタイルに合わせたプロジェクト内CSSを使っています。

依存ライブラリの版は `package.json` と `package-lock.json` に固定しています。React 19.3.1、Vite 8.3.5、react-moveable 0.56.0、react-selecto 1.26.3、react-resizable-panels 4.14.8、Leaflet 1.9.4、Ajv 8.20.0を使用します。

### 右クリックと色変更

- 編集中の部品・配置済み一覧: 複製、色変更、最前面／最背面、この端末で表示／非表示、削除。
- キャンバス空白: すべて選択、全体表示、Undo/Redo。
- Shift・Ctrl・Commandを押しながらクリックすると選択の追加／解除。選択中の部品を右クリックしても複数選択を維持し、未選択の部品ならその部品へ切り替える。
- Shift+F10またはメニューキーでも開く。上下キー・Home/Endで移動、Enter/Spaceで実行、Esc/Tabで閉じて元の対象へフォーカスを戻す。外側のクリック・スクロール・画面サイズ変更でも閉じる。
- 入力欄と試す画面では独自メニューを表示しない。
- 色変更は背景色・文字色・枠線色。パレット、カラーピッカー、6桁HEXで指定し、変更した項目だけを「適用」で一括反映する。取り消す・Escは設計を変更しない。枠線がない場合は枠線色の適用で1pxの枠を付ける。
- 色はPC／スマホ共通。表示・重なり順は操作中の端末だけに適用する。地図タイル・写真の色は変更しない。
- 色・表示・重なり順・複製・削除は1操作ずつUndo/Redoできる。設計JSONとプロンプトにも反映する。

新しい依存関係は追加していません。型検査・本番ビルドが成功しました。今回、テストスイートは実行していません。画面記録は `../../../design/verification/context-menu/` にあります。

## 公開と地図ダウンロード

公開エディターは `/builder/sketch/` です。利用者のインストールは不要です。上部の「地図をダウンロード」から閲覧用HTMLを保存し、ブラウザーで直接開けます。編集した配置・データ・動作を含み、内部列と元の接続URLを除外します。背景地図と写真にはインターネット接続が必要です。再編集にはプロジェクトメニューの設計JSONを保存してください。

初回は当初の牛久市マップの21地点（2026年10月14日の保存データ）を表示します。保存済みの設計がある場合はそちらを復元します。プロジェクトメニューから当初の牛久市マップを画面内に表示したり、21地点を編集用に読み込み直せます。地点の最新性と座標の正確性は確認が必要です。
