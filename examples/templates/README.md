# machi. 汎用地図の完成例

3つの設計は、同じ架空の12地点を使っています。地点名・説明・座標は表示検証用です。実在する施設の案内には使用しないでください。

| ファイル | 使い方の例 |
| --- | --- |
| `map.machi.json` | 地図を中心に見せ、必要なときに一覧を開く |
| `list.machi.json` | 地図と地点一覧を並べて探す |
| `guide.machi.json` | 説明文を読んでから地図を使う |

## 開き方と編集

1. 現在作業中の設計がある場合、プロジェクトメニューから「設計JSONを書き出す」でバックアップします。
2. 同じメニューの「JSONを読み戻す」から、使いたい完成例を選びます。差分を確認し「取り込む」を押すと作業中の設計が置き換わります。Undoでも取り込み前に戻せます。
3. データから表を取り込み、列の対応と掲載する項目を確認して反映します。`sample-data.csv` は編集用の出発点です。
4. PCとスマホの配置をそれぞれ確認し、「試す」で検索、カテゴリ、一覧、詳細を操作します。
5. 「プロンプト」から現在の設計をコピーまたはMarkdownとして保存し、外部AIへ渡します。見本の `list-implementation.md` は、編集前の一覧併設型から生成した実装指示です。編集後は必ず新たに出力してください。

## AIによる実装の照合

`list-implementation.md` のみを普段使うAIへ渡し、React・TypeScript・Leafletの地図アプリを作ってもらいます。AIへエディターのソースや画面画像を渡さず、生成されたソースを保存してください。

実装結果はPC 1280×800、スマホ390×844で確認します。12地点のデータ、画面の文言、検索、カテゴリ、一覧・ピンの選択、詳細の開閉を照合します。主要部品の外枠について、設計と生成結果の位置・寸法の差が各8px以内であることを目安にします。地図タイル画像の差は判定に含めません。問題が出た場合は、指示の不足と生成結果の問題を分けて記録します。

実際の生成結果との照合は、外部AIからソースを受け取るまで未実施です。
