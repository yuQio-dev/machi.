# 地点取り込みの確認用データ

値は操作確認用の架空データです。編集画面の「データ」→「地点データを取り込む」で使えます。

## Excel

`multiple-sheets.xlsx` の最初の「空のシート」では空表のエラーが出ます。シート選択で「地点データ」に切り替えると、B12から始まる見出しを12行目と認識します。13行目は有効、14行目は緯度なしの不正行です。「不正な1行を除外して取り込む」を選ぶと1件を反映できます。「別の地点」は1行目に見出しがある別シートです。見出し行を変更すると列対応が再判定されます。

## CSV

`places.csv` はUTF-8 BOM付きです。名称内のカンマと紹介文内の改行、座標が空の不正行を含みます。有効1件、不正1件になります。

## Google Sheets

自分で公開可能な表を使う場合は、上記CSVをシートに取り込み、対象タブを開いた共有URLを入力します。リンクを知っている全員が閲覧できる設定か、対象シートをウェブに公開する必要があります。共有設定を変更する前に公開範囲を確認してください。URLの `gid` は対象タブを選び、指定がない場合はGoogleの既定のシートを取得します。URLから取得できるのは1回につき1シートです。通信・権限・ブラウザーの制約で取得できない場合は、CSVまたはExcelとして保存して取り込めます。OAuth、非公開表へのアクセス、自動同期はありません。

外部の例として、[HandsOnDataVizの公開テンプレート](https://docs.google.com/spreadsheets/d/1XvtkzuVyQ_7Ud47ypDJ4KOmz_5lOpC9sqeEDBbJ5Pbg/edit#gid=0)でも確認できます。2026-10-30には「住所」の列を「使用しない」、「スポット名」の列を「Location」に設定して8件を反映できました。外部の表や公開設定は変更される場合があります。

`node scripts/build-import-examples.mjs` でこの2ファイルを再生成できます。`npm test` はこれらの例、URLの変換、取得失敗、元の行番号、データセットへの反映を確認します。
